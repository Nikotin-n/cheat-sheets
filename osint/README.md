
## 🔍 OSINT Cheat Sheets

This section is dedicated to passive web reconnaissance methodologies, infrastructure analysis tools, and open-source security auditing.

The documentation covers the following core areas:
* **Alternative Search Engines:** Leveraging specialized search engines to uncover hidden infrastructure components, exposed directories, and specific file types.
* **Global IoT Infrastructure Reconnaissance:** Techniques for non-intrusive network reconnaissance, analyzing open ports, running services, and device signatures.
* **Historical Web Analysis & Legacy Architecture:** Utilizing web archives and global data dumps to investigate website evolution, retrieve legacy components, and analyze deleted web content.
* **Legacy Parameter & Vulnerability Surface Discovery:** Uncovering forgotten configurations, staging environments, and obsolete access points that may present security risks.
