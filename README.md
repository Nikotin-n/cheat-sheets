# 📚 Cybersecurity Cheat Sheets & Notes

This repository contains a structured collection of personal cheat sheets, reference guides, command lists, and methodology notes used in various cybersecurity domains.

The goal of this repository is to keep essential commands, syntax, and workflows organized for quick access during practical tasks, CTFs, and security assessments.

---

## 📌 Main Categories

The documentation covers key operational areas:

* **OSINT & Reconnaissance:** Search operators, OSINT workflows, and data-gathering techniques.
* **Linux & Networking:** Essential CLI commands, networking utilities, and system administration references.
* **Web Security:** Payload structures, common attack vectors, and web testing methodologies.
* **Security Tools:** Quick reference guides for popular tools (e.g., Nmap, Wireshark, Burp Suite).
* **CTF & Decoding:** Common encoding/decoding schemes, cryptography tricks, and quick-solver references.

---

## 🛠️ Purpose & Usage

This is a living documentation repository. It is updated regularly as new tools, techniques, and methodologies are learned and tested in practice.
